# Installation

## Requirements

- Node.js 20+
- macOS or Linux (Windows is not first-class yet)

## npm (recommended)

```bash
npm install -g @arokodev/cli
aroko --version
```

## Verify

```bash
aroko doctor
```

Doctor checks project config, runtime health, and coding-agent availability.
