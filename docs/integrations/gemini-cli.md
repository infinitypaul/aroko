# Gemini CLI

## Setup

```bash
aroko init --provider gemini-cli
```

Ensure the Gemini CLI is on your PATH, then start collaborating with
`aroko connect`.

## What you can do

- Inspection-oriented collaboration through Aroko

## Limitation

Structured change proposals are not supported with Gemini CLI yet. Use Cursor
or Claude Code when you need propose → approve → apply.

## Compatibility

Requires a working `gemini` CLI on PATH. Use `aroko doctor` to verify.
